# Premium Store | وب‌سایت مستقل و ربات تلگرام

نسخه ۳ وب‌سایت در [premium-store](premium-store/) قرار دارد. [راهنمای کامل نصب و امکانات](premium-store/README.md) و [گزارش بررسی ۴۲ آزمون](premium-store/docs/verification.md).

ورود موبایلی و نشست دو روزه، صفحه محصول و سفارش، تخفیف، کیف پول و بازپرداخت، تیکت و چت، پیام‌رسانی SMS/تلگرام، پرونده مشتری، مدیریت کارت و فعال‌سازی با یادآوری برداشت و مجوزهای جزئی کارکنان اضافه شده‌اند. شماره کارت و رمز اکانت‌ها رمزگذاری می‌شوند.

**همگام‌سازی محصولات سایت و ربات حذف شده است.** سایت دیتابیس ربات را باز نمی‌کند. اتصال اختیاری پیام خروجی ربات مستقل است. فایل‌های ربات اصلی در `botversion1.8` تغییری نکرده‌اند.

پرداخت و شارژ بانکی فعلاً آزمایشی‌اند؛ درگاه واقعی هنوز پیاده نشده است. پیام خروجی در محیط توسعه ارسال واقعی ندارد؛ راه‌اندازی production نیازمند سرویس پیامکی/توکن و کلید رمزگذاری خصوصی است. هیچ دیتابیس یا کلید خصوصی سایت وارد مخزن نشده است.

## راهنمای قبلی ربات
# bot

ربات تلگرامی با پنل مدیریت تحت وب.

## اجرای ربات تلگرام

```bash
pip install -r requirements.txt  # در صورت استفاده از فایل نیازمندی‌ها
python -m app.main
```

## اجرای پنل وب ادمین

1. در فایل `.env` مقادیر زیر را تنظیم کنید:
   ```env
   ADMIN_WEB_USER=admin
   ADMIN_WEB_PASS=very-secret
   ADMIN_WEB_BIND=0.0.0.0
   ADMIN_WEB_PORT=8080
   ```
2. پیش‌نیازها را نصب کنید:
   ```bash
   pip install fastapi uvicorn jinja2 python-dotenv
   ```
3. سرور وب را اجرا کنید:
   ```bash
   python admin_web.py
   ```

پنل وب شامل داشبورد، مدیریت سفارش‌ها، مشاهده کاربران و گزارش تراکنش‌های کیف پول است و به صورت پیش‌فرض روی پورت 8080 در دسترس خواهد بود.
