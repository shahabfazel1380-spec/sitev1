# Premium Store | فروشگاه وب و ربات تلگرام

نسخه جدید وب‌سایت در [premium-store](premium-store/) قرار دارد. **راهنمای کامل نصب ویندوز و Ubuntu، ساخت مدیر، پیامک، دسترسی کارکنان، اتصال ربات، HTTPS و بکاپ:** [README وب‌سایت](premium-store/README.md).

امکانات: ورود موبایلی با نشست دو روزه، پروفایل و سفارش‌ها، صفحه اختصاصی محصول و رسانه، کد تخفیف، چت و تیکت جدا، پنل مدیریت با مجوزهای جزئی و صف همگام‌سازی محصولات با ربات.

وضعیت: پیامک محلی و پرداخت آزمایشی؛ برای راه‌اندازی عملیاتی باید سرویس پیامکی انتخاب و درگاه واقعی پیاده‌سازی شود. نسخه production پرداخت آزمایشی را قبول نمی‌کند. داده‌های ربات اصلی در `botversion1.8` در این تغییر دست‌نخورده مانده‌اند. هیچ دیتابیس، رمز یا فایل محیطی جدیدی برای سایت اضافه نشده است.

## راهنمای قبلی ربات
# bot

ربات تلگرامی با پنل مدیریت تحت وب.

## اجرای ربات تلگرام

```bash
pip install -r requirements.txt  # در صورت استفاده از فایل نیازمندی‌ها
python -m app.main
```

## اجرای پنل وب ادمین

1. در فایل `.env` مقادیر زیر را تنظیم کنید:
   ```env
   ADMIN_WEB_USER=admin
   ADMIN_WEB_PASS=very-secret
   ADMIN_WEB_BIND=0.0.0.0
   ADMIN_WEB_PORT=8080
   ```
2. پیش‌نیازها را نصب کنید:
   ```bash
   pip install fastapi uvicorn jinja2 python-dotenv
   ```
3. سرور وب را اجرا کنید:
   ```bash
   python admin_web.py
   ```

پنل وب شامل داشبورد، مدیریت سفارش‌ها، مشاهده کاربران و گزارش تراکنش‌های کیف پول است و به صورت پیش‌فرض روی پورت 8080 در دسترس خواهد بود.
